# Учебная конфигурация 1С: Управление туристическими поездками

Учебный проект по курсу «Разработчик 1С».

---

## Описание проекта

Конфигурация предназначена для автоматизации продажи туров и управления поездками. Реализован полный цикл: от ведения справочников до оформления договоров, предварительных соглашений, оплат и отчетности.

---

## Функциональные возможности

**Справочники:**
- Организации
- Сотрудники
- Агенты
- Клиенты
- Страны мира
- Города мира
- Отели
- Виды номеров гостиниц
- Валюты
- Роли сотрудников

**Документы:**
- Договор
- Предварительное соглашение
- Оплата

**Отчеты (СКД):**
- Статистика по поездкам

**Регистры накопления:**
- Продажи туров
- Взаиморасчеты с клиентами

**Подсистемы:**
- Менеджмент
- Бухгалтерия
- Аналитика

**Прочее:**
- Общая форма
- Общие картинки (3 шт.)
- Печатная форма договора
- Перечисления: Статус клиента, Пол, Категории гостиниц
- Стили: БирюзаКорп, СтрСинийКорп

## Как развернуть

**Вариант 1 — из XML-выгрузки:**

1. Установите учебную версию 1С:Предприятие 8.3.
2. Создайте новую информационную базу.
3. Откройте Конфигуратор → **Конфигурация → Загрузить конфигурацию из файлов**.
4. Укажите путь к папке с выгрузкой.
5. Запустите 1С:Предприятие в режиме «Управляемое приложение».

**Вариант 2 — из файла .dt:**

1. Установите учебную версию 1С:Предприятие 8.3.
2. Откройте Конфигуратор → **Администрирование → Загрузить информационную базу**.
3. Выберите файл `1C-MechtaPuteshestvennika-Portfolio.dt`.
4. Запустите 1С:Предприятие.
